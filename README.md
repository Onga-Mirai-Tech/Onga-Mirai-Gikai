# みらい議会 -遠賀町版-

遠賀町議会の会議録をもとに、議事の流れと「誰が何を言い、町がどう答えたか」をわかりやすく見せる**個人運営の非公式サイト**です。

> **お断り**
> - 本サイトは個人が運営する非公式サイトです。遠賀町・遠賀町議会・「チームみらい」とは一切関係ありません。
> - AIによる要約を含みます。正確な内容は必ず原典（遠賀町議会 会議録検索システム）をご確認ください。
> - 議員・会派・町に対する評価、点数付け、ランキングは行いません。

## 構成

静的サイト（HTML / CSS / JS / JSON のみ）です。収集・整形・AI要約・サイト生成は GitHub Actions 上のパイプラインで行い、生成物をエックスサーバーへ配置します。実行時のサーバー処理・DB は使いません。

```
pipeline/   データ収集〜サイト生成のパイプライン（Python）
  fetch/      会議録の取得
  parse/      発言分割・発言者判定・議案抽出
  summarize/  AI要約（Claude Batch API）
  verify/     数字・固有名詞の照合チェック
  build/      静的サイト生成
data/
  raw/         原文HTML
  normalized/  整形済みJSON
  summaries/   AI要約JSON
  masters/     発言者マスタ・会派・役職履歴
  state.json   最終確認日時・取得済み一覧
site/
  templates/  ページテンプレート
  assets/     CSS・JS・フォント（外部CDN不使用）
docs/       設計ドラフト・調査報告
dist/       生成物（git管理外）
```

## 使い方

Python 3.12 以降。**依存ライブラリはありません**（標準ライブラリのみ）。

```bash
# 何件取りに行くかだけ確認する（ネットワークにはつながない）
python -m pipeline.fetch.voices --dry-run

# 会議録を取得する。取得済みはスキップされる
python -m pipeline.fetch.voices

# 一般質問通告書・審議案件結果のPDFを取得する
python -m pipeline.fetch.town

# パーサのテスト
python -m unittest discover -s pipeline/tests -t .
```

`pipeline.fetch.voices` は日本時間の深夜帯（0〜6時）以外では実行を拒否します。
これは CLAUDE.md の取得マナーによるものです。動作確認のときは `--limit` と
`--allow-daytime` を付けてください。

取得した原文は `data/` に入りますが、**このリポジトリには含めません**。
理由と構成は [docs/設計ドラフト.md](docs/設計ドラフト.md) の「3. 全体構成 → リポジトリ構成」を参照してください。
